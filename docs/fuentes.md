# Fuentes - Sistema Pacientes

## 1. Documentación oficial

1. **Oracle.** (s. f.). *Java SE 21 Specifications*.  
   [https\://docs.oracle.com/javase/specs/jls/se21/html/index.html](https://docs.oracle.com/javase/specs/jls/se21/html/index.html) **Consulta y aplicación:** especificación del lenguaje Java 21 como referencia para interpretar la sintaxis y el comportamiento del código.  
2. **Oracle.** (s. f.). *Java Platform, Standard Edition 21 API Specification*.  
   [https\://docs.oracle.com/en/java/javase/21/docs/api/index.html](https://docs.oracle.com/en/java/javase/21/docs/api/index.html) **Consulta y aplicación:** referencia de clases y métodos de la biblioteca estándar de Java.  
3. **Apache Maven.** (s. f.). *Introduction to the Standard Directory Layout*.  
   [https\://maven.apache.org/guides/introduction/introduction-to-the-standard-directory-layout.html](https://maven.apache.org/guides/introduction/introduction-to-the-standard-directory-layout.html) **Consulta y aplicación:** estructura convencional de proyectos Maven, en particular `src/main/java`, `src/test/java`, recursos y `target/`.  
4. **Apache Maven.** (s. f.). *Maven in 5 Minutes*.  
   [https\://maven.apache.org/guides/getting-started/maven-in-five-minutes.html](https://maven.apache.org/guides/getting-started/maven-in-five-minutes.html) **Consulta y aplicación:** conceptos iniciales de Maven, archivo `pom.xml` y ciclo básico de construcción. Recurso de apoyo para la preparación del entorno.  
5. **OpenCSV.** (s. f.). *OpenCSV Documentation*.  
   [http\://opencsv.sourceforge.net/](http://opencsv.sourceforge.net/) **Consulta y aplicación:** referencia de la biblioteca para lectura y escritura de archivos CSV.  
6. **OpenCSV.** (s. f.). *OpenCSV \--- source repository*. GitHub.  
   [https\://github.com/JodaOrg/opencsv](https://github.com/JodaOrg/opencsv) **Consulta y aplicación:** repositorio del proyecto, código y documentación asociada a la biblioteca. La versión declarada en el proyecto revisado es OpenCSV 5.9.  
7. **GitHub.** (s. f.). *About protected branches*. GitHub Docs.  
   [https\://docs.github.com/en/repositories/configuring-branches-and-merges-in-your-repository/managing-protected-branches/about-protected-branches](https://docs.github.com/en/repositories/configuring-branches-and-merges-in-your-repository/managing-protected-branches/about-protected-branches) **Consulta y aplicación:** fundamentos de protección de ramas, revisiones y restricciones para integrar cambios en ramas importantes como `main`.  
8. **Miro.** (s. f.). *Miro Help Center*.  
   [https\://help.miro.com/](https://help.miro.com/) **Consulta y aplicación:** centro de ayuda utilizado como referencia general para incorporar y organizar contenido en tableros. La importación concreta debe verificarse según las opciones disponibles en la cuenta y el formato del archivo.

## 2. Documentación no oficial y recursos complementarios

9. **Baeldung.** (s. f.). *Introduction to OpenCSV*.  
   [https\://www\.baeldung.com/opencsv](https://www.baeldung.com/opencsv) **Consulta y aplicación:** explicación práctica de OpenCSV y ejemplos de lectura y escritura de datos CSV. Se utiliza como complemento de la documentación del proyecto.  
10. **Baeldung.** (s. f.). *Apache Maven Tutorial*.  
    [https\://www\.baeldung.com/maven](https://www.baeldung.com/maven) **Consulta y aplicación:** material introductorio complementario sobre Maven, dependencias y construcción de proyectos Java.  
11. **GeeksforGeeks.** (s. f.). *Java Programming Language*.  
    [https\://www\.geeksforgeeks.org/java/java](https://www.geeksforgeeks.org/java/java/) **Uso previsto:** material complementario para repasar programación orientada a objetos, colecciones, excepciones y conceptos de Java. No se atribuyen a esta fuente decisiones específicas ya adoptadas en el proyecto.  
12. **Stack Overflow.** (s. f.). *Java questions*.  
    [https\://stackoverflow.com/questions/tagged/java](https://stackoverflow.com/questions/tagged/java\\) **Uso previsto:** consulta complementaria para investigar errores concretos y contrastar alternativas. Las respuestas deben verificarse con documentación confiable y pruebas antes de aplicarse.
