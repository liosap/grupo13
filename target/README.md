# Instructivo: Sistema de Pacientes

Para poder ejecutar la aplicación correctamente en tu computadora, sigue los pasos detallados a continuación.

### 📣 Requisito previo

Debes tener instalado **Java Runtime Environment ([JRE](https://adoptium.net/de/temurin/releases))** en tu computadora. Si aún no lo tienes, asegúrate de instalarlo antes de continuar.

### Método 1: Ejecutar mediante la Terminal o Línea de Comandos (Recomendado)

Esta opción es la más segura, ya que te permite ver mensajes de estado o posibles errores si algo llegara a fallar.

1. **Abre la terminal** o consola de comandos de tu sistema operativo.
2. **Navega hasta la carpeta** donde se encuentra guardado el archivo `.jar` utilizando el comando `cd` seguido de la ruta de la carpeta:

```bash
cd ruta/de/la/carpeta
```

3. **Ejecuta el siguiente comando** para iniciar el sistema:

```bash
java -jar SistemaPacientes-1.0-SNAPSHOT.jar
```

### Método 2: Ejecución directa (Doble clic)

En muchos sistemas operativos (especialmente en **Windows**), si Java está configurado de forma predeterminada para abrir archivos con extensión `.jar`, no necesitas usar la terminal,simplemente haz **doble clic** sobre el archivo `SistemaPacientes-1.0-SNAPSHOT.jar` y la aplicación se abrirá de inmediato.
